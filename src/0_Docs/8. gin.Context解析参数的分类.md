# Gin Context 参数获取方式

## 1. URL 路径参数 (Path Parameters)
```go
// 路由定义: GET /user/:address
userAddr := c.Params.ByName("address")
```

## 2. URL 查询参数 (Query Parameters)
```go
// URL: /items?chain_id=1&limit=10
chainID := c.Query("chain_id")           // 获取单个参数
limit := c.DefaultQuery("limit", "20")    // 带默认值
```

## 3. POST 表单参数 (Form Parameters)
```go
// Content-Type: application/x-www-form-urlencoded
name := c.PostForm("name")
age := c.DefaultPostForm("age", "18")
```

## 4. 请求体参数 (Body Parameters)
```go
// Content-Type: application/json
var user User
if err := c.ShouldBindJSON(&user); err != nil {
    // 处理错误
}
```

## 5. Header 参数
```go
token := c.GetHeader("Authorization")
contentType := c.GetHeader("Content-Type")
```

## 6. 文件上传
```go
file, err := c.FormFile("file")
if err != nil {
    // 处理错误
}
```

## 7. 上下文键值对
```go
// 设置
c.Set("user", user)

// 获取
if user, exists := c.Get("user"); exists {
    // 使用user
}
```

## 8. 原始请求信息
```go
// 获取原始请求
body, _ := c.GetRawData()
// 获取请求方法
method := c.Request.Method
// 获取请求URL
url := c.Request.URL.String()
```

## 9. 参数验证示例
```go
type User struct {
    Name string `form:"name" binding:"required"`
    Age  int    `form:"age" binding:"min=1,max=100"`
}

var user User
if err := c.ShouldBind(&user); err != nil {
    // 处理验证错误
}
```

## 10. 注意事项
1. `c.Query()` 用于获取 URL 查询参数
2. `c.Param()` 用于获取 URL 路径参数
3. `c.PostForm()` 用于获取表单数据
4. `c.ShouldBindJSON()` 用于解析 JSON 请求体
5. 所有参数获取方法都有对应的 Default 版本，可以设置默认值
