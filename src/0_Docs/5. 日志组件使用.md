# xzap 日志组件使用教程

## 1. xzap.SetUp(c.Log) 的作用

`xzap.SetUp(c.Log)` 是日志系统的初始化函数，它完成了以下工作：

### 1.1 基础配置检查
```go
if len(c.Path) == 0 {
    return nil, ErrLogPathNotSet
}
```
- 检查日志路径是否设置
- 设置默认日志保留天数（7天）

### 1.2 日志模式配置
支持两种模式：
- `consoleMode`: 控制台输出模式
- `volumeMode`: 文件输出模式

### 1.3 日志级别设置
```go
setupLogLevel(c)
```
根据配置设置日志级别

### 1.4 初始化 zap.Logger
```go
return &ZapLogger{
    Logger: logger,
    Opts:   opts,
}, nil
```

## 2. 项目中的使用方式

### 2.1 获取日志实例
```go
// 获取全局日志实例
logger := xzap.GetZapLogger()

// 获取上下文日志实例
ctxLogger := xzap.WithContext(ctx)
```

### 2.2 日志记录方法
```go
// 基础日志
ctxLogger.Info("message")
ctxLogger.Error("message", zap.Error(err))

// 格式化日志
ctxLogger.Infof("format %s", "message")
ctxLogger.Errorf("error: %v", err)
```

### 2.3 在服务中的使用示例
```go
// 在 service 中使用
func (s *Service) DoSomething(ctx context.Context) error {
    logger := xzap.WithContext(ctx)
    
    logger.Info("start doing something")
    
    if err := doSomething(); err != nil {
        logger.Error("failed to do something", zap.Error(err))
        return err
    }
    
    logger.Info("successfully done")
    return nil
}
```

## 3. 高级特性

### 3.1 gRPC 拦截器
```go
// 在 xgrpc/interceptors.go 中
func GrpcMessageProducer(ctx context.Context, msg string, level zapcore.Level, err error, fields []zapcore.Field) {
    fields = append(fields, zap.Error(err))
    cl := xzap.WithContext(ctx)
    cl.Extract().Check(level, msg).Write(fields...)
}
```

### 3.2 结构化日志
```go
// 添加结构化字段
logger.Info("user login",
    zap.String("user_id", "123"),
    zap.Time("login_time", time.Now()),
    zap.Duration("response_time", time.Since(start)),
)
```

## 4. 最佳实践

1. **使用上下文日志**：始终使用 `xzap.WithContext(ctx)` 获取日志实例
2. **结构化日志**：使用 zap.Field 添加结构化信息
3. **错误日志**：使用 `zap.Error(err)` 记录错误
4. **日志级别**：合理使用不同级别的日志（Debug/Info/Warn/Error）

这个日志系统基于 zap 实现，提供了高性能的结构化日志记录能力，支持上下文传递和 gRPC 集成。
