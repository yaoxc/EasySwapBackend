

# handler 方法中 c *gin.Context 参数是在哪里设置值的?

如下面Handler：
```go
func GetSigStatusHandler(svcCtx *svc.ServerCtx) gin.HandlerFunc {
	return func(c *gin.Context) {
		userAddr := c.Params.ByName("address")
		if userAddr == "" {
			xhttp.Error(c, errcode.NewCustomErr("user addr is null"))
			return
		}

		res, err := service.GetSigStatusMsg(c.Request.Context(), svcCtx, userAddr)
		if err != nil {
			xhttp.Error(c, errcode.NewCustomErr(err.Error()))
			return
		}

		xhttp.OkJson(c, res)
	}
}

```


`c *gin.Context` 参数的值是在 Gin 框架的路由匹配过程中自动设置的。让我为你详细解析这个过程：

### 1. 路由注册
在 `router.go` 中，路由被注册到 Gin 引擎：
```go
func loadV1(r *gin.Engine, svcCtx *svc.ServerCtx) {
    // ... 其他路由
    v1.GET("/user/:address/sig-status", v1.GetSigStatusHandler(svcCtx))
}
```

### 2. 请求处理流程
1. HTTP 请求到达服务器
2. Gin 框架根据 URL 路径匹配路由
3. 匹配成功后，Gin 自动创建 `gin.Context` 实例
4. 将 URL 参数（如 `address`）解析到 `c.Params`
5. 调用对应的 handler 函数，传入 `gin.Context`

### 3. Context 的主要功能
```go
type Context struct {
    Request   *http.Request    // HTTP 请求
    Writer    ResponseWriter   // HTTP 响应写入器
    Params    Params          // URL 路径参数
    Keys      map[string]interface{} // 上下文键值对
    // ... 其他字段
}
```

### 4. 参数获取
```go
userAddr := c.Params.ByName("address")  // 从 URL 路径参数获取
```

### 5. 中间件处理
在 `router.go` 中设置的中间件会先处理请求：
```go
r.Use(middleware.RecoverMiddleware())  // 恢复中间件
r.Use(middleware.RLog())              // 日志中间件
r.Use(cors.New(...))                   // CORS 中间件
```

### 6. 上下文传递
```go
c.Request.Context()  // 获取请求的上下文，用于传递请求级别的值
```

> 所以，`gin.Context` 是 Gin 框架在处理 HTTP 请求时自动创建和管理的，它包含了请求的所有相关信息，包括 URL 参数、请求头、请求体等.
> 你不需要手动设置它，框架会自动处理这些细节。
